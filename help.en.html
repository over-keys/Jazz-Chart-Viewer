Jazz Chart Viewer

Display, transpose, and read iReal-format jazz chord charts directly in your browser. This guide covers the complete workflow from importing Jazz 1460 to expanding repeats and adjusting notation.

Quick start

  1. Open the gear button and choose Import iReal data.
  2. Paste an iReal shared link or choose a saved text or HTML file, then select Import.
  3. Choose a song from the search box.
  4. Use − / + to change key, and Auto / ♭ / ♯ to control spelling.
  5. Use Original for the written chart or Expanded for linear performance order.

Import songs

Import Jazz 1460

Open the official iReal Pro community forum topic and find the Jazz 1460 link in the first post.

Open Jazz 1460 forum topic
  1. Copy the Jazz 1460 link itself. Do not copy the browser's page address.
  2. On a computer, right-click the link and choose Copy link address or Copy Link. On a phone or tablet, touch and hold it and choose Copy Link.
  3. Confirm that the copied text begins with irealb:// or irealbook://.
  4. In the viewer, open Settings → Import iReal data, paste the link, and select Import.
Replacing an older full playlistWhen replacing Jazz 1410 or another older complete Jazz playlist, use Delete all songs first so obsolete or renamed charts do not remain.

Import other iReal data

You can paste any irealb:// or irealbook:// shared link, or choose a saved .txt, .html, or .htm file.

Imports are merged with the current library. A chart with the same title and composer replaces the existing copy; other songs remain.

Find and select a song

Select the search box to show all imported songs, then type part of a title. Choose a result with the mouse or touch. With a keyboard, use Up / Down to move, Enter to select, and Escape to close the list.

When you change songsThe temporary transposition resets to the selected song's original key.

Change key and note spelling

− / +Transpose the displayed key and every chord down or up by one semitone.
AutoChoose flats or sharps according to the transposed key.
♭Prefer flat spellings, such as B♭ and E♭.
♯Prefer sharp spellings, such as F♯ and C♯.

Transposition affects only the displayed chart. The imported source data is not modified.

Original and Expanded views

Original

Shows the chart as written, including repeat signs, first and second endings, D.C., D.S., Fine, Segno, To Coda, and Coda markings.

Expanded

Turns the navigation into a linear top-to-bottom sequence that can be read in performance order.

Expanded view resolves written repeats and numbered endings. Supported D.C. and D.S. instructions are followed through Fine or Coda when those markings are present. Repeat dots and ending brackets are removed from the expanded sequence, while musical section boundaries remain visible as double barlines.

Use Original as the referenceExpanded view follows standard navigation rules encoded in the imported chart. If a source uses unusual text instructions or malformed repeat data, compare it with Original and treat Original as authoritative.

Size and screen controls

Scale sliderSets a manual chart size and turns Auto off.
AutoFits the chart to the available viewport again.
FullscreenEnters or exits browser fullscreen where supported.

The layout keeps four measures per row, including on mobile screens, and scales the whole page to fit. Time-signature changes, rehearsal marks, double barlines, repeats, endings, Segno, Coda, and final barlines are preserved where present in the source chart.

Settings

Open the gear button to:

  • choose the display style for major, minor, half-diminished, and diminished chords;
  • import more iReal data;
  • delete all imported songs;
  • reset display settings to their defaults.

Delete all songs removes the imported library but leaves the built-in demonstration chart. Reset settings does not delete imported songs.

Local storage and privacy

Songs and settings are stored locally in IndexedDB for the exact site URL. Jazz Chart Viewer does not upload your song library.

Re-import songs after clearing browser data, changing browser or device, or opening the viewer at a different domain or repository path. Private or incognito mode may discard the library when the private session ends.

MuseJazz Text font (optional)

The viewer tries to load MuseJazz Text automatically. To install it locally:

  1. Download MuseJazzText.otf.
  2. Open it and choose Install on Windows or Install Font on macOS. On Linux, copy it to ~/.local/share/fonts/ and run fc-cache -f.
  3. Restart the browser.

If the font is unavailable, the viewer uses the standard △ symbol instead.

Troubleshooting

The import says no iReal data was found.
Confirm that the pasted text begins with irealb:// or irealbook:// and was not truncated.
The pasted text begins with https://forums.irealpro.com/.
You copied the forum page address. Copy the Jazz 1460 link itself.
Selecting Jazz 1460 opens iReal Pro.
Return to the forum and copy the link with right-click or touch-and-hold instead of opening it.
Imported songs disappeared.
Browser data may have been cleared, or the site's URL changed. Import the playlist again.
The chart is too small or too large.
Select Auto, or move the Scale slider to set a manual size.
Expanded order looks wrong.
Compare with Original and check whether the source chart uses nonstandard or incomplete navigation markings.
The major symbol looks different.
Install MuseJazz Text, or continue using the standard △ fallback.
